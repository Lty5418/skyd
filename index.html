更新日志

持续打磨中的手感与工具

最近四次重要更新，点击可展开查看完整条目。

  • 编辑器属性栏大改版：新增方块通用属性（隐藏 / 可击碎 / 幻象 / 背景 / 靠近短暂亮起）
  • 全新事件触发系统：广播触发后可执行切换隐藏、移动到固定点、两点往返移动
  • 新增主角表情眼睛（方形 / 竖形两种样式，可开关）：随移动、跳跃、攻击、受击变换表情，支持怒气变红与待机犯困
  • 移动平台现在可以在属性栏直接编辑路径点；移除「双重方块」工具，旧关卡兼容保留
  • 修复自定义攻击键位置不生效的问题；击碎方块现可正确消失；幻象方块恢复外观原样
  • 多选方块时属性不一致的选项自动隐藏，防止误操作
  • 首页背景与手册截图体积优化，总文件体积 -15%
  • 重构统一碰撞检测系统：所有物体（玩家、木箱、移动平台）独立计算碰撞
  • 木箱完全独立于网格，不再覆盖传送门 / 出生点 / 存档点 / 弹板
  • 修复木箱破碎后残留碰撞体积的问题；木箱现在可以与移动平台正确碰撞
  • 移动平台颜色改为与普通陆地一致
  • 增大虚拟摇杆尺寸：默认 150px（原 120px），thumb 56px（原 48px）
  • 增大跳跃按钮尺寸：默认 100px（原 80px），字体 26px（原 22px）
  • 增大游戏内顶部按钮（重新开始 / 退出）与返回按钮的尺寸、字号
  • 摇杆最大拖拽距离改为动态计算，适配不同屏幕尺寸；各响应式断点同步增大控件尺寸
  • 时空中枢界面改版：3 列正方形卡片布局，点击卡片进入详情页，顶部显示地图全貌预览
  • 添加设备检测：自动识别电脑端与移动端；电脑端支持鼠标左右键操作
  • 电脑端编辑器新增「移动」工具，左键直接拖拽画布
  • 重写全部 20 个内置关卡，优化难度曲线，新增「死亡螺旋」「不可能任务」等最终关卡
